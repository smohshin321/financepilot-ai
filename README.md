# FinancePilot AI

> AI-Powered Enterprise Financial Planning & Analysis (FP&A) Platform

FinancePilot AI is a commercial-grade FP&A platform designed to demonstrate enterprise finance expertise, modern software engineering, and applied artificial intelligence.

## Tech Stack

### Backend
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker

### Frontend (Upcoming)
- Streamlit
- Plotly
- Power BI

### AI & Machine Learning (Upcoming)
- Scikit-learn
- XGBoost
- Prophet
- OpenAI
- RAG
- AI Copilot
